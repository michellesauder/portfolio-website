# GotCare Healthcare Platform

A comprehensive national healthcare platform built with modern AWS infrastructure and React frontend, serving healthcare providers and patients across Canada.

## Project Overview

GotCare is a national healthcare platform that connects patients with healthcare providers, streamlining the healthcare delivery process. As a Senior Software Engineer at Four Nine Digital, I led the full-stack development and AWS infrastructure implementation.

## Technical Implementation

### Frontend Development
- **React & Next.js**: Built responsive, accessible user interfaces
- **TypeScript**: Type-safe development with comprehensive error handling
- **Tailwind CSS**: Modern, responsive design system
- **GSAP & Framer Motion**: Smooth animations and micro-interactions
- **WCAG Compliance**: Full accessibility standards implementation

### Backend Architecture
- **AWS ECS Fargate**: Containerized microservices architecture
- **Aurora PostgreSQL**: Scalable, managed database solution
- **GraphQL**: Efficient data fetching and real-time updates
- **Lambda Functions**: Serverless compute for specific workflows
- **EventBridge**: Event-driven architecture for system integration

### Infrastructure & DevOps
- **AWS CDK (TypeScript)**: Infrastructure as Code
- **Cognito**: User authentication and authorization
- **CloudFront**: Global content delivery network
- **WAF**: Web application firewall for security
- **GitHub Actions**: CI/CD pipeline for automated deployments

## Key Achievements

- **Scalability**: Designed system to handle national healthcare traffic
- **Security**: Implemented HIPAA-compliant security measures
- **Performance**: Achieved sub-300ms response times for critical operations
- **Accessibility**: Full WCAG AA compliance for inclusive healthcare access
- **Reliability**: 99.9% uptime with automated monitoring and alerting

## Impact

The platform successfully serves healthcare providers and patients nationwide, improving healthcare accessibility and streamlining provider workflows. The scalable architecture supports future growth and feature expansion.

## Technologies Used

- React, Next.js, TypeScript
- AWS (ECS, Lambda, Aurora, CloudFront, Cognito, WAF)
- GraphQL, PostgreSQL, Redis
- Docker, GitHub Actions
- Tailwind CSS, GSAP, Framer Motion
